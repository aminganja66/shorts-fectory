# Music library (do this once, ~20 minutes)
Download 15–25 copyright-safe tracks into this folder and list each one in library.json:
  {"file": "dark-docu-01.mp3", "title": "...", "author": "...", "mood": "documentary", "license": "YouTube Audio Library – no attribution required", "url": "..."}
Sources: YouTube Studio → Audio Library (filter "Attribution not required"), or Pixabay Music.
Moods used: documentary, tension, cinematic (brand) · mysterious, ambient, lofi (psych).
Keep each file under ~5 MB — they are committed to git so both laptops have them.
